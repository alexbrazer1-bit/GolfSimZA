# GolfSim ZA — Phase 0.6.1

## Real-Golf Play HUD Polish

This stage refines the 0.6 play-round screen toward the approved simulator-style reference.

### Included
- Persistent top course / hole header.
- Dedicated shot-data panel for club, ball speed, club speed, launch, direction, spin, carry and total.
- Central playing view with hole, pin and current-ball indicators.
- Right-side player leaderboard with player name, score, shot count and distance to pin.
- Hole mini-map.
- Club selector styling consistent with the simulator UI.
- Active-player highlighting.
- Existing 0.6 turn flow and shot/flight logic retained.
- Existing course, tee, hole and player session data retained.

### Design direction
The gameplay screen should feel like a golf simulator first and a prototype UI second. The approved dark teal / blue visual language is now the baseline for subsequent stages.

2. Add a proper scorecard / hole-by-hole round summary.
3. Add camera controls and shot-view transitions.
4. Add putting-specific HUD behavior.
