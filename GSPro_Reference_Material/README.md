# GSPro Reference Material

Temporary working area for GSPro-related files supplied for analysis during GolfSimZA development.

## Purpose

Files placed in this folder may be reviewed to understand file structures, course metadata, scoring data, coordinate/data formats, and other technical information relevant to building our own GolfSimZA systems.

## Important

- This folder is temporary and is intended to be removed when the analysis/development stage is complete.
- Do not commit proprietary, confidential, or copyrighted material unless you have the right to store it in this repository.
- We will build our own implementation rather than copying proprietary code or assets.
